طريقة النشر من الهاتف — GitHub + Render

1) فك الضغط.
2) افتح مستودع GitHub الحالي.
3) استبدل الملفات بالنسخة الجديدة في جذر المستودع.
4) لا تنشئ public ولا src/public.
5) في Render افتح Web Service نفسه.
6) Build Command: npm install
7) Start Command: npm start
8) اضغط Manual Deploy ثم Deploy latest commit.
9) انتظر حتى تظهر Live.
10) افتح رابط الموقع من الهاتف.

إذا ظهر الخطأ القديم ENOENT الخاص بـ public/index.html، فالإعداد القديم لم يتحدث. هذه النسخة تخدم index.html من جذر المشروع.
