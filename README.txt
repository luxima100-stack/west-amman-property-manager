نسخة عقارات غرب عمّان — إصدار نهائي للرفع

مهم:
1) هذه الحزمة تحتوي الملفات في الجذر بدون مجلدات.
2) التصميم مبني على المواصفات المرفقة: واجهة RTL داكنة فاخرة، بطاقات الشقق، البحث الأفقي، الصور، واتساب، التنبيهات، العقود، المستأجرون، الإعدادات، المديرون، المحادثات، النسخ الاحتياطي والملف الشخصي.
3) لحفظ الصور وقاعدة البيانات فعلياً يجب ربط المشروع بمشروع Supabase الخاص بك.

الخطوات:
- افتح supabase.sql في Supabase > SQL Editor ونفّذه.
- أنشئ حساب المالك من Authentication > Users.
- أضف صف المالك في جدول profiles كما هو موضح في آخر الملف.
- افتح config.js وضع Supabase URL و anon/public key فقط.
- ارفع جميع الملفات الموجودة هنا إلى مستودع GitHub نفسه بدون إنشاء مجلد.
- في Render اختر Web Service/Node، واربطه بالمستودع. Build Command: npm install، Start Command: npm start. أضف متغيرات البيئة SUPABASE_URL و SUPABASE_SERVICE_ROLE_KEY، ولا تضع service_role داخل config.js.
- افتح الموقع وسجّل دخول المالك.

الصور:
- يسمح JPG/PNG/WEBP.
- الرفع المتعدد.
- الصور تُرفع إلى Supabase Storage أولاً ثم تحفظ روابطها داخل سجل الشقة.
- يمكن اختيار الصورة الرئيسية وحذف الصور.
- يوجد دعم فيديو اختياري.

واتساب:
- تجهيز نص منسق للتفاصيل.
- حتى 10 صور عند استخدام مشاركة النظام في الهاتف إذا كان المتصفح يدعم مشاركة الملفات.
- يوجد fallback لفتح WhatsApp بالنص عند عدم دعم مشاركة الملفات.

الأمان:
- لا تضع service_role key في config.js.
- تغيير كلمة مرور المستخدم الحالي يتم من Supabase Auth.
- لا يمكن للواجهة الثابتة تغيير كلمة مرور مستخدم آخر بأمان دون Edge Function/خادم بصلاحية service_role. لذلك زر "تغيير كلمة سر المالك" يفتح تغيير كلمة مرور حساب المالك المسجّل حالياً.

ملاحظة مهمة:
لا يمكنني الادعاء أن اتصال Supabase الفعلي مكتمل قبل وضع بيانات مشروعك الحقيقية في config.js. بقية الحزمة تعمل، وعند عدم وجود إعدادات Supabase تعرض رسالة واضحة بدلاً من شاشة سوداء.


التحقق من النسخ السابقة:
تمت مراجعة ملفات المشروع السابقة الموجودة في مكتبة الملفات. ملف التحقق السابق يذكر أن نسخة 18.0.0 كانت مسطحة الجذر، وبها app_state، وتنسيق أفقي لسجل البحث/التنبيهات، وأزرار إغلاق للنوافذ. كما تمت مراجعة مصدر سابق يتضمن رفع الصور إلى Supabase Storage وإنشاء المديرين بصلاحية المالك.

هذه الحزمة الحالية تعيد بناء الواجهة والوظائف من المواصفات المرفقة وتضيف server.js لحماية عمليات إدارة الحسابات.
