# West Amman Rentals — نسخة جديدة من الصفر

تطبيق إدارة وتأجير شقق عربي RTL يعمل على الهاتف والكمبيوتر، مبني بـ Node.js + Express + SQLite.

## التشغيل
1. ثبّت Node.js 20+.
2. داخل مجلد المشروع شغّل `npm install` ثم `npm start`.
3. افتح `http://localhost:3000`.

بيانات المالك الأولية: `owner` / `Owner@1234` — غيّرها فورًا قبل الاستخدام الفعلي.

## ملاحظات مهمة
- النسخة الحالية هي أساس عملي متكامل للواجهة والـAPI والصلاحيات وإدارة الشقق والصور والمستأجرين والمالية والمهام.
- SQLite وملفات الصور المحلية مناسبة للتجربة/الاستضافة ذات التخزين الدائم. على Render المجاني، التخزين المحلي ليس قاعدة مناسبة للإنتاج؛ عند النشر النهائي ننقل قاعدة البيانات والملفات إلى خدمة تخزين/قاعدة بيانات دائمة.
- مشاركة واتساب تستخدم واجهة واتساب الخاصة بالهاتف. إرسال أكثر من 15 صورة يعتمد على إمكانيات نظام الهاتف/واتساب، ولا يمكن للموقع تجاوز حدود التطبيق نفسه.
