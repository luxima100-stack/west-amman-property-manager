# غرب عمّان — منصة إدارة وتأجير الشقق

## تشغيل
1. ثبّت Node.js 18+.
2. داخل المجلد شغّل: `npm install`
3. ثم: `npm start`
4. افتح `http://localhost:3000`

## الدخول الأول
- المستخدم: `owner`
- كلمة المرور: `Owner@1234`

غيّر كلمة المرور قبل النشر العام.

هذه نسخة تشغيلية أولى كاملة الهيكل مع قاعدة SQLite محلية، رفع صور وملفات، شقق، مستأجرين، مالية، مهام، وأدمن. لمشاركة الصور عبر واتساب بكاملها يعتمد السلوك النهائي على قيود نظام الهاتف/واتساب؛ زر واتساب يرسل تفاصيل الشقة مباشرة.
