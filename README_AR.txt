# عقارات غرب عمان — FINAL 19.0.0

هذه النسخة مسطحة من دون مجلدات داخلية. الملفات الأساسية موجودة في جذر المشروع.

## أهم الإصلاحات
- البحث يعرض الشقق المطابقة فقط ولا يضيف خانة نتائج أسفل الشقق.
- سجل البحث يظهر كشريط أفقي أعلى نتائج البحث.
- صور JPG / PNG / WEBP تُرفع إلى Supabase Storage ثم تُحفظ روابطها داخل سجل الشقة قبل الحفظ.
- لا توجد حقول اسم المستأجر أو رقمه أو وصف الشقة في نموذج إضافة الشقة.
- الإعدادات أصبحت صفحة كاملة ومتصلة بـ Supabase.
- صلاحيات المدير باللغة العربية.
- المالك يستطيع تغيير كلمة سر حسابه، ومن داخل الإعدادات تغيير كلمة سر حساب المالك.
- زر × موجود في النوافذ المنبثقة.
- التنبيه الخاص بقرب توفر الشقة محفوظ لكل شقة.
- جميع بيانات الشقق والإعدادات وسجل البحث تعتمد على Supabase.
- Service Role Key لا يوضع في app.js؛ يبقى في Render Environment Variables فقط.

## Render Environment Variables
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
SUPABASE_BUCKET=property-images
OWNER_EMAIL

نفّذ SUPABASE_SETUP_WEST_AMMAN.sql مرة واحدة في Supabase SQL Editor.

## ملاحظة أمنية
لا تضع SUPABASE_SERVICE_ROLE_KEY داخل GitHub أو أي ملف يصل إلى المتصفح.
