نسخة نهائية 18.4.0 — عقارات غرب عمان

هذه النسخة مبنية على تصميم النسخة القديمة، مع تصحيح رفع وحفظ الصور والإعدادات والمناطق.

1) ارفع الملفات إلى GitHub مباشرة بدون مجلد.
2) في Render تأكد من وجود SUPABASE_URL و SUPABASE_SERVICE_ROLE_KEY.
3) إذا كان لديك Bucket باسم property-images لا تحذفه. شغّل SQL مرة واحدة فقط عند الحاجة.
4) لا تضع SUPABASE_SERVICE_ROLE_KEY داخل ملفات المشروع أو GitHub.
5) الصور ترفع عبر الخادم إلى Supabase Storage ثم تحفظ روابطها داخل properties.images.

النسخة لا تحتاج إلى إنشاء قاعدة جديدة إذا كانت قاعدة المشروع القديمة موجودة.
