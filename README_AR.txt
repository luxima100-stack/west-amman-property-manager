عقارات غرب عمان — النسخة 18.2.0

هذه النسخة تحافظ على تصميم النسخة القديمة 18 وتحتوي على إصلاحات محددة فقط.

أهم الإصلاحات:
1) إصلاح رفع الصور: الصور المختارة تبقى محفوظة حتى الضغط على حفظ، ثم تُرفع إلى Supabase Storage وتُحفظ روابطها مع الشقة.
2) دعم JPG / PNG / WEBP حتى 10 صور للشقة.
3) إضافة alert_days إلى قاعدة البيانات حتى لا تضيع مدة التنبيه بعد إعادة تحميل التطبيق.
4) الإعدادات أصبحت صفحة نظام كاملة بالعربية: واتساب، أيام التنبيه، عنوان ووصف الصفحة، المظهر، أنواع الصور، ومناطق غرب عمان.
5) نقل تغيير كلمة مرور المالك بالكامل إلى صفحة «إدارة المديرين والصلاحيات» كما طلب المستخدم.
6) صلاحيات المديرين معروضة بالعربية، وتشمل «إدارة المديرين».
7) الحفاظ على تصميم النسخة القديمة وعدم إعادة تصميم التطبيق.
8) الملف مسطح بدون مجلدات.

متطلبات Render:
- Build: npm install
- Start: npm start
- متغيرات البيئة المطلوبة: SUPABASE_URL و SUPABASE_SERVICE_ROLE_KEY، ويمكن تحديد SUPABASE_BUCKET و OWNER_EMAIL.

متطلبات Supabase:
- تنفيذ ملف SUPABASE_SETUP_WEST_AMMAN.sql على مشروع Supabase الحالي، خصوصاً إضافة alert_days إذا كانت القاعدة القديمة لا تحتوي عليه.
- يجب أن يكون Bucket property-images عاماً لعرض الصور بروابط public.

ملاحظة: لا تحذف قاعدة البيانات الحالية ولا تنشئ مشروع Supabase جديداً إذا كانت البيانات الحالية صحيحة.
