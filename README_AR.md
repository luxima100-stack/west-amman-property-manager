# نظام إدارة عقارات غرب عمّان — الإصدار 5.8

## أبرز تحديثات 5.8
- مشاركة تفاصيل الشقة كصورة PNG منظمة، وليست كرابط.
- مشاركة الصور كصور فعلية عبر مشاركة الهاتف.
- مشاركة الفيديو كوسائط فيديو عبر مشاركة الهاتف.
- تشغيل الفيديو داخل نافذة مصغرة عند الضغط عليه.
- السعر ظاهر للمالك فقط في واجهة العقارات ومشاركة التفاصيل؛ لا يظهر للـAdmin في بطاقة العقار.
- بحث في إدارة العقارات حسب السعر وعدد الغرف ونوع الإيجار.
- أنواع الإيجار: يومي / شهري / سنوي.
- خانة مستقلة للإيجار اليومي والشهري والسنوي.
- كود مستقل لكل شقة.
- موعد توفر وتنبيه قرب التوفر بعدد أيام يحدده المستخدم.
- مسح سجل العمليات للمالك مع تأكيد ظاهر على الواجهة.
- تأكيد ظاهر قبل تعديل أو حذف بيانات الشقة والصور والفيديو والسجل.
- ألوان كحلي/بنفسجي وذهبي بطابع فاخر، وخط أوضح، وأزرار بتأثير 3D.
- الحفاظ على PWA وSQLite وJWT والصلاحيات Owner/Admin/User.

## Render
Build Command: `npm install`
Start Command: `npm start`

## الحسابات التجريبية
owner / 1234
admin / 1234
user / 1234

قبل فتح النظام للعامة: غيّر كلمات المرور، اضبط JWT_SECRET قوي، وفعل HTTPS.

## النسخة 5.13
- زر حفظ نسخة كاملة للمالك يحفظ قاعدة البيانات والصور والمستندات وملفات الموقع في ملف backup واحد.
- لا يتم حذف البيانات عند تحديث ملفات الواجهة؛ البيانات محفوظة في data.db وuploads.
- يجب استخدام تخزين دائم للسيرفر عند النشر حتى تبقى data.db وuploads بعد إعادة النشر.
- تم إخفاء قسم الفيديو من نافذة تفاصيل الشقة حسب طلب المستخدم.
- زر تجديد المستأجر يعمل بضغطة واحدة: أحمر = غير قابل للتجديد، أخضر = قابل للتجديد.
- واجهة رئيسية جديدة مع شعار 3D وصورة عقارية محلية.

## تحديث v5.20 — الاسترجاع الآمن
- استرجاع أي نسخة من آخر 10 نسخ للمالك فقط.

## الإصدار 5.26 — حماية الصور وتوسيع المشاركة
- السماح بتحديد حتى 30 صورة في نافذة مشاركة الصور.
- تحسين مشاركة الصور دون إزالة ميزة الاختيار.
- حماية الصور وقاعدة البيانات من الضياع عند تحديث التطبيق عبر دعم DATA_ROOT/PERSISTENT_DATA_DIR.
- على Render يجب توجيه PERSISTENT_DATA_DIR إلى مسار Persistent Disk، لأن ملفات Free المحلية مؤقتة.

## الإصدار 5.26.1 — إصلاح فشل التشغيل
- إصلاح ترتيب تعريف مسار التخزين الدائم قبل إنشاء مسار قاعدة البيانات.
- النسخة جاهزة لإعادة النشر بعد ضبط التخزين الدائم.

## الإصدار 5.28 — تحسين عرض الهاتف
- عرض 6 صور مصغرة على كرت الشقة في الهاتف (3 أعمدة × صفين).
- تكبير الخطوط في الهاتف إلى حجم أوضح وأسهل للقراءة.

## الإصدار 5.29 — تحسين الخطوط
- تكبير حجم الخطوط بشكل عام في التطبيق إلى حجم واضح قريب من حجم كتابة الهاتف.
- جعل النصوص داكنة/سوداء لزيادة الوضوح.
- جعل العناوين أكبر قليلًا من النص الأساسي مع وزن أوضح.

## الإصدار 5.30 — الخط والأزرار
- تكبير الخط العام إلى 20px ليتضح على الهاتف.
- العناوين أكبر وأثقل من النص الأساسي.
- جعل النصوص سوداء/داكنة.
- جعل الأزرار بلون ذهبي فاتح مع كتابة سوداء واضحة.


## الإصدار 5.31 — كلمات المرور وصلاحيات Admin
- إعادة خاصية إظهار/إخفاء كلمات المرور لجميع حقول كلمات المرور الديناميكية.
- إضافة صلاحيات مستقلة للـAdmin يمكن للمالك تفعيلها أو إلغاؤها: الشقق والعقارات، المستأجرون والحجوزات، الدفعات والمالية، المحادثة، وسجل العمليات.
- الصلاحيات تُحفظ في قاعدة البيانات ويُتحقق منها على السيرفر، وليس في الواجهة فقط.

## الإصدار 5.32 — أزرار ذهبية فاخرة 3D
- توحيد أزرار الواجهة بلون ذهبي فاخر بتدرج لوني وتأثير 3D.
- إضافة تأثير رفع عند المرور وضغط واقعي عند النقر.
- الحفاظ على أزرار الحالة/الحذف ذات الدلالة الخاصة، مع تنسيق متناسق.


## الإصدار 5.33 — صفحات المستخدمين والصلاحيات
- إعادة زر إظهار/إخفاء كلمة المرور بشكل موثوق حتى داخل النوافذ الديناميكية.
- عند إضافة Admin أو User تظهر صفحة صلاحيات باسم المستخدم.
- صلاحيات Admin: الشقق والعقارات، المستأجرون والحجوزات، الدفعات والمالية، المحادثة، سجل العمليات.
- صلاحيات User: عرض الشقق، عرض المستأجرين والحجوزات، عرض الدفعات، عرض المحادثة، عرض السجل.
- يمكن للمالك فتح صفحة أي Admin/User لاحقًا وتعديل الصلاحيات.

## الإصدار 5.34 — أزرار 3D ناعمة
- تخفيف بروز الأزرار وجعل تأثير 3D ناعمًا ومتناسقًا مع واجهة الموقع.
- تقليل الظلال والتدرجات القوية مع الحفاظ على اللون الذهبي الفخم.
- تأثير لمس وضغط خفيف بدل الشكل البارز الحاد.

## الإصدار 5.35 — السجل والصور
- إصلاح حذف سجل العمليات من قاعدة البيانات للمالك.
- إزالة زر تحديد الكل من منطقة الصور المحمّلة فقط.
- جعل زر حذف الصورة أصغر وأهدأ ولونه باهتًا ومتناسقًا مع التصميم.


## الإصدار 5.36 — النسخ والحماية والصلاحية الرئيسية
- وضع النسخ الاحتياطي والحماية في صفحة مستقلة بتصميم هادئ وأزرار ذهبية فاتحة.
- إضافة صلاحية "الدخول للصفحة الرئيسية" يمكن للمالك منحها لـAdmin أو User.
- حفظ صلاحية الصفحة الرئيسية ضمن صلاحيات المستخدم.


## الإصدار 5.37 — إصلاح فعلي للقائمة والصلاحيات
- إصلاح إدراج صفحة النسخ الاحتياطي والحماية داخل نظام التنقل والـView الفعلي.
- إصلاح خطأ دالة إضافة المستخدم الذي كان يمنع تشغيل بعض وظائف الصفحة.
- إضافة صلاحية الصفحة الرئيسية داخل صفحة صلاحيات Admin وUser.
- جعل صفحة الصلاحيات تُفتح مباشرة بعد إنشاء المستخدم.
