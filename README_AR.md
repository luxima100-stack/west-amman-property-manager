# نظام إدارة عقارات غرب عمّان

نسخة Web App متجاوبة للهاتف والكمبيوتر، جاهزة للرفع إلى GitHub ثم نشرها على Render.

## المزايا
- تسجيل دخول وصلاحيات Owner / Admin / User.
- إدارة الشقق والمناطق والحالات والإيجارات.
- إدارة المستأجرين والعقود.
- تسجيل الدفعات.
- رفع المستندات والصور.
- سجل العمليات.
- تصدير CSV.
- واجهة عربية RTL متجاوبة.
- PWA قابلة للتثبيت على الهاتف.

## حسابات التجربة
owner / 1234
admin / 1234
user / 1234

## النشر على Render
Build Command: npm install
Start Command: npm start

قبل الاستخدام الفعلي غيّر كلمات المرور التجريبية.
