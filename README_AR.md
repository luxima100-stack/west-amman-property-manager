# نظام إدارة عقارات غرب عمّان — النسخة النهائية

## المزايا
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر.
- PWA قابلة للتثبيت على الهاتف.
- SQLite قاعدة بيانات مشتركة على السيرفر.
- تسجيل دخول حقيقي باستخدام JWT.
- كلمات المرور مخزنة بتشفير bcrypt.
- صلاحيات Owner / Admin / User.
- إدارة الشقق: المنطقة، الحالة، الإيجار، المساحة، الغرف، الحمامات، الطابق والملاحظات.
- إدارة المستأجرين والعقود.
- تسجيل الدفعات وطرق الدفع.
- رفع المستندات والصور حتى 10MB.
- سجل العمليات.
- تصدير الشقق CSV.
- لوحة إحصائيات.
- قائمة واسعة من مناطق وأحياء غرب عمّان.

## التشغيل لأول مرة على Windows
1. ثبّت Node.js 20 LTS أو أحدث.
2. فك ضغط الملف.
3. افتح PowerShell داخل مجلد المشروع.
4. نفّذ:
   npm install
5. ثم:
   npm start
6. افتح في الكمبيوتر:
   http://localhost:3000

## الحسابات التجريبية
owner / 1234
admin / 1234
user / 1234

## تشغيله على الهاتف داخل نفس Wi‑Fi
1. شغّل البرنامج على الكمبيوتر.
2. في Windows نفّذ `ipconfig`.
3. ابحث عن IPv4 Address، مثلاً 192.168.1.20.
4. من الهاتف على نفس شبكة Wi‑Fi افتح:
   http://192.168.1.20:3000
5. من قائمة المتصفح اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق".

## جعله متاحاً من أي مكان
النسخة جاهزة للنشر على VPS/سيرفر Node.js.
قبل النشر يجب:
- ضبط JWT_SECRET قوي.
- تغيير كلمات المرور التجريبية.
- تفعيل HTTPS.
- عمل نسخة احتياطية لملف data.db ومجلد uploads.
- يفضّل PostgreSQL إذا كبر النظام وعدد المستخدمين.

## مهم
هذه نسخة تشغيلية قوية كبنية أساسية، وليست بديلاً عن اختبار أمني شامل قبل استخدامها مع بيانات حساسة أو فتحها للعامة على الإنترنت.
