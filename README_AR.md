# عقارات غرب عمان — النسخة النهائية المسطحة

هذه النسخة تعيد التصميم الداكن الفاخر السابق وتجمع الوظائف المطلوبة في ملفات جذرية فقط، بدون مجلدات.

## ما تم تثبيته
- نفس هوية التصميم الداكن + الذهبي القديمة.
- صفحة هبوط بدون سجل بحث أسفل الشقق.
- شريط تنبيه أفقي للشقق القريبة من التوفر.
- البحث والتصفية: المنطقة، الحالة، الغرف، الحمامات، البلكونة، السعر والترتيب.
- إضافة/تعديل/حذف الشقق.
- رفع حتى 10 صور JPG/PNG/WEBP إلى Supabase Storage ثم حفظ روابطها في قاعدة البيانات، بدلاً من تخزين Base64 داخل الشقة.
- عرض الصور في البطاقة والتفاصيل، مع عداد الصور.
- زر واتساب وتجهيز تفاصيل الشقة.
- نافذة تفاصيل مع زر X.
- جميع النوافذ المنبثقة تحتوي على X وإلغاء.
- دخول المالك والمدير فقط.
- صفحة عربية للمالك والمديرين.
- المالك فقط يستطيع إنشاء مدير وتغيير كلمات المرور.
- الصلاحيات محفوظة لكل مدير.
- إعدادات المناطق وعدد أيام تنبيه قرب التوفر.
- نسخة احتياطية JSON للمالك.
- محادثات داخلية.
- تقارير وإحصائيات.
- تصميم متجاوب للهاتف والكمبيوتر.
- جميع ملفات المشروع في الجذر، لا public ولا src.

## Render
Build Command: npm install
Start Command: npm start

## Environment Variables
SUPABASE_URL=رابط مشروع Supabase
SUPABASE_SERVICE_ROLE_KEY=مفتاح Service Role
OWNER_EMAIL=بريد المالك (اختياري لكنه موصى به)
SUPABASE_BUCKET=property-images (اختياري)

نفّذ SUPABASE_SETUP_WEST_AMMAN.sql مرة واحدة في Supabase SQL Editor.
