# نظام إدارة عقارات غرب عمّان — الإصدار 5.8

## أبرز تحديثات 5.8
- مشاركة تفاصيل الشقة كصورة PNG منظمة، وليست كرابط.
- مشاركة الصور كصور فعلية عبر مشاركة الهاتف.
- مشاركة الفيديو كوسائط فيديو عبر مشاركة الهاتف.
- تشغيل الفيديو داخل نافذة مصغرة عند الضغط عليه.
- السعر ظاهر للمالك فقط في واجهة العقارات ومشاركة التفاصيل؛ لا يظهر للـAdmin في بطاقة العقار.
- بحث في إدارة العقارات حسب السعر وعدد الغرف ونوع الإيجار.
- أنواع الإيجار: يومي / شهري / سنوي.
- خانة مستقلة للإيجار اليومي والشهري والسنوي.
- كود مستقل لكل شقة.
- موعد توفر وتنبيه قرب التوفر بعدد أيام يحدده المستخدم.
- مسح سجل العمليات للمالك مع تأكيد ظاهر على الواجهة.
- تأكيد ظاهر قبل تعديل أو حذف بيانات الشقة والصور والفيديو والسجل.
- ألوان كحلي/بنفسجي وذهبي بطابع فاخر، وخط أوضح، وأزرار بتأثير 3D.
- الحفاظ على PWA وSQLite وJWT والصلاحيات Owner/Admin/User.

## Render
Build Command: `npm install`
Start Command: `npm start`

## الحسابات التجريبية
owner / 1234
admin / 1234
user / 1234

قبل فتح النظام للعامة: غيّر كلمات المرور، اضبط JWT_SECRET قوي، وفعل HTTPS.

## النسخة 5.13
- زر حفظ نسخة كاملة للمالك يحفظ قاعدة البيانات والصور والمستندات وملفات الموقع في ملف backup واحد.
- لا يتم حذف البيانات عند تحديث ملفات الواجهة؛ البيانات محفوظة في data.db وuploads.
- يجب استخدام تخزين دائم للسيرفر عند النشر حتى تبقى data.db وuploads بعد إعادة النشر.
- تم إخفاء قسم الفيديو من نافذة تفاصيل الشقة حسب طلب المستخدم.
- زر تجديد المستأجر يعمل بضغطة واحدة: أحمر = غير قابل للتجديد، أخضر = قابل للتجديد.
- واجهة رئيسية جديدة مع شعار 3D وصورة عقارية محلية.

## الإصدار 5.26 — حماية الصور وتوسيع المشاركة
- السماح بتحديد حتى 30 صورة في نافذة مشاركة الصور.
- تحسين مشاركة الصور دون إزالة ميزة الاختيار.
- حماية الصور وقاعدة البيانات من الضياع عند تحديث التطبيق عبر دعم DATA_ROOT/PERSISTENT_DATA_DIR.
- على Render يجب توجيه PERSISTENT_DATA_DIR إلى مسار Persistent Disk، لأن ملفات Free المحلية مؤقتة.
