# عقارات غرب عمان — FINAL 18.1

هذه النسخة مصممة لتكون **مسطحة بدون مجلدات داخل ملف ZIP** ومناسبة للنشر على Render وربطها بـ Supabase.

## الملفات
- `index.html` الواجهة الرئيسية.
- `app.css` التصميم الفخم + التصاميم الأربعة + العرض المتجاوب.
- `app.js` الوظائف والواجهة.
- `server.js` تسجيل الدخول، الصلاحيات، قاعدة البيانات، رفع الصور، المديرون، النسخ الاحتياطية.
- `SUPABASE_SETUP_WEST_AMMAN.sql` إنشاء جداول Supabase وStorage bucket.
- `render.yaml` إعداد Render.
- `package.json` الاعتمادات.
- `manifest.json` دعم تثبيت الموقع كتطبيق على الهاتف.

## المطلوب في Supabase
1. أنشئ مشروع Supabase.
2. افتح SQL Editor والصق كامل `SUPABASE_SETUP_WEST_AMMAN.sql` ثم Run.
3. أنشئ حساب المالك في Authentication > Users إذا لم يكن موجوداً.
4. في Render أضف:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `OWNER_EMAIL` = بريد حساب المالك
   - `SUPABASE_BUCKET` = `property-images`

## تسجيل الدخول
يستخدم التطبيق Supabase Auth بالبريد وكلمة المرور. أول حساب مالك يمكن ربطه تلقائياً بصفحة `profiles` إذا كان هو `OWNER_EMAIL` ولا يوجد مالك مسجل بعد.

## المديرون
من حساب المالك فقط يمكن إنشاء مدير جديد بالبريد وكلمة المرور وتحديد الصلاحيات.

## الصور
رفع JPG / PNG / WEBP حتى 10 صور للشقة. الصور الجديدة ترفع إلى Supabase Storage ولا تُحفظ داخل ملفات المشروع.

## واتساب
زر واتساب في بطاقة الشقة يفتح شاشة اختيار حتى 10 صور ويجهز النص مع الإيموجي. على Android/Chrome، `navigator.share` يمرر الصور كملفات إلى قائمة المشاركة ومنها WhatsApp عندما يسمح المتصفح والنظام بذلك. إذا لم يدعم المتصفح مشاركة الملفات، يفتح واتساب بالنص كحل احتياطي.

## ملاحظة مهمة
لا يمكن لأي ملف برمجي وحده أن يضمن «100%» نجاح النشر إذا كانت متغيرات Supabase في Render خاطئة أو إذا لم يتم تشغيل SQL. هذه النسخة تعالج ذلك بإظهار أخطاء واضحة بدلاً من شاشة سوداء.
