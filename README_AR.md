# نظام إدارة عقارات غرب عمّان — الإصدار 5.8

## أبرز تحديثات 5.8
- مشاركة تفاصيل الشقة كصورة PNG منظمة، وليست كرابط.
- مشاركة الصور كصور فعلية عبر مشاركة الهاتف.
- مشاركة الفيديو كوسائط فيديو عبر مشاركة الهاتف.
- تشغيل الفيديو داخل نافذة مصغرة عند الضغط عليه.
- السعر ظاهر للمالك فقط في واجهة العقارات ومشاركة التفاصيل؛ لا يظهر للـAdmin في بطاقة العقار.
- بحث في إدارة العقارات حسب السعر وعدد الغرف ونوع الإيجار.
- أنواع الإيجار: يومي / شهري / سنوي.
- خانة مستقلة للإيجار اليومي والشهري والسنوي.
- كود مستقل لكل شقة.
- موعد توفر وتنبيه قرب التوفر بعدد أيام يحدده المستخدم.
- مسح سجل العمليات للمالك مع تأكيد ظاهر على الواجهة.
- تأكيد ظاهر قبل تعديل أو حذف بيانات الشقة والصور والفيديو والسجل.
- ألوان كحلي/بنفسجي وذهبي بطابع فاخر، وخط أوضح، وأزرار بتأثير 3D.
- الحفاظ على PWA وSQLite وJWT والصلاحيات Owner/Admin/User.

## Render
Build Command: `npm install`
Start Command: `npm start`

## تحديث 5.43.1 — حماية التطبيق وروابط المشاركة
- لا يمكن فتح لوحة إدارة التطبيق أو أي مسار إداري مباشرة بدون تسجيل الدخول.
- جميع واجهات API محمية بالمصادقة، باستثناء تسجيل الدخول نفسه وفحص الصحة.
- صفحة `/property/:id` هي الاستثناء الوحيد المقصود: صفحة عامة للشقة عند مشاركة الرابط ولا تتطلب تسجيل الدخول.
- أي رابط آخر غير معروف يعيد المستخدم إلى شاشة تسجيل الدخول.
- مشاركة الشقة من داخل النظام تستخدم رابط العرض العام للشقة، وليس رابط التطبيق الإداري.
