# نظام إدارة عقارات غرب عمّان — التحديث النهائي 5.2

هذه الحزمة مخصصة لتحديث المستودع الحالي على GitHub ثم إعادة النشر على Render.

## أهم ما تم إصلاحه
- عدة صور للشقة JPG/PNG/WEBP.
- صورة مصغرة وعدد الصور وحذف الصور.
- فيديو للشقة.
- مربع واضح لحالة الشقة.
- تفاصيل كاملة قابلة للنسخ.
- مشاركة المالك فقط للتفاصيل وروابط الصور والفيديو.
- الغرف والحمامات والصالات والصالونات والبلكونات في التفاصيل والبحث.
- موعد توفر لكل شقة + عدد أيام التنبيه لكل شقة.
- عداد أحمر أعلى لوحة التحكم يعرض الشقق القريبة من التوفر مع الكود وموعد التوفر.
- تغيير كلمة المرور من داخل التطبيق.
- محادثة المالك وAdmin.
- إصلاح مشكلة الصور التي ترفع بنجاح ثم لا تظهر بسبب التخزين المؤقت؛ لم يعد Service Worker يخزن API أو الصور/الفيديو.
- إجبار API على جلب البيانات الحديثة بدون Cache.

## Render
Build Command: npm install
Start Command: npm start

بعد رفع الملفات إلى GitHub:
1. افتح خدمة Render.
2. افتح Events.
3. اختر آخر Deploy متعلق بآخر Commit.
4. إذا لم يبدأ تلقائياً استخدم Manual Deploy / Deploy latest commit.
5. انتظر حتى يظهر Deploy succeeded.
6. افتح رابط التطبيق.

## إذا بقيت النسخة القديمة في الهاتف
أغلق تبويب التطبيق، ثم افتح الرابط من جديد. إذا كان التطبيق مثبتاً على الشاشة الرئيسية، افتح الرابط في Chrome مرة واحدة وانتظر تحميل النسخة الجديدة، ثم أعد فتح التطبيق.

ملاحظة: ملفات uploads وSQLite على الاستضافة المجانية قد لا تكون تخزيناً دائماً؛ للاستخدام الفعلي يجب إضافة تخزين دائم/خارجي ونسخ احتياطية.


## تحديث 5.3 — صور الشقة
- السماح برفع حتى 30 صورة في عملية رفع واحدة لكل شقة.
