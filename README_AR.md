# مشروع عقارات غرب عمان — v14.0.0

هذه النسخة مخصصة للعمل من الهاتف والكمبيوتر بواجهة متجاوبة.

## التعديلات الرئيسية
- سجل البحث في صفحة الهبوط/الرئيسية.
- سجل البحث يحفظ: النص، المنطقة، الحالة، الغرف، الحمامات، البلكونة فقط.
- لا يحفظ الصالات أو النوع أو ترتيب الأحدث.
- شريط تنبيه أسفل صورة/واجهة الصفحة الرئيسية.
- التنبيه يعتمد على بيانات المستأجر: موعد الإيجار، انتهاء العقد، وعدد أيام التنبيه.
- نافذة تنبيه مرئية مع صور الشقق القريبة من التوفر.
- إعدادات الصوت: تشغيل/إيقاف، مستوى الصوت، نغمة مخصصة، وتجربة النغمة.
- واتساب: تجهيز التفاصيل بالنص المطلوب وتحديد حتى 10 صور تلقائياً مع إمكانية تعديل الاختيار.
- تفاصيل واتساب: كود الشقة، المنطقة، الغرف، الحمامات، بلكونة نعم/لا، السعر، وتاريخ التوفر فقط إذا كانت الشقة غير متاحة.
- صفحة المستأجرين: الاسم، الهاتف، موعد الإيجار، انتهاء العقد، ملف الهوية/الجواز، والتجديد أخضر/أحمر.
- إدارة المديرين والصلاحيات باللغة العربية.
- المالك يستطيع تغيير كلمة المرور وإظهارها/إخفاءها.
- إزالة صفحة العقود نهائياً من القائمة والتوجيه.

## Render
